☁️ Google Drive 同期（iPhone/PC間でデータ共有） 未設定

（変更があると3秒後に自動アップロード／開いた時に最新を取得）
📁 保存先： Google Drive内の タスク管理v3-同期データ フォルダ → data.json
📍 初回作成場所： マイドライブ直下（その後ご自身で 開発部門 配下へ移動可能・追跡継続）
🔒 同期されるもの： タスク・時間記録・カテゴリ・月額設定・税務カレンダー設定
🚫 同期されないもの： 計測中タイマー・連携設定（端末ごと）
⚠️ 注意： 1つの端末で計測 → ストップしてから別端末で次の計測。同時計測すると二重記録になります。
① Google Cloud Console で新規プロジェクト作成 → 「APIとサービス」→「ライブラリ」→ Google Drive API を有効化
② 「APIとサービス」→「OAuth同意画面」で外部・ユーザータイプを設定（自分のメールを追加）
③ 「認証情報」→ 「OAuth クライアントID」を作成（種類：ウェブアプリケーション）
④ 承認済みJavaScriptオリジンに https://【ユーザー名】.github.io を追加
⑤ クライアントIDをここにコピペ → 「設定を保存」→「Driveに認証して同期」

📅 Googleカレンダー 未設定

① GoogleクラウドコンソールでOAuthクライアントID（ウェブアプリ）を作成してください。
② 承認済みのJavaScriptオリジンに null または file:// を追加してください。
③ 「認証」→「書き出す」の順に実行します。未完了タスク（期限あり）が登録されます。

💬 Chatwork 未設定

① Chatworkの設定 > API でAPIトークンを発行してください。
② 書き出したいチャットのルームIDを入力してください（URLの末尾の数字）。
③「取り込む」→ タスク一覧で選択 → インポート実行。「書き出す」→ 新規タスクをChatworkに登録。
